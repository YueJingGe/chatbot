# 高度抖动和滚动问题

打字机不断更新内容，消息气泡的高度不断增加，推动整个聊天区域高度变化，引起父容器滚动条的不断显示隐藏，滚动条的显隐也会引起宽度的变化，才会出现抖动的感觉

并且，用 setState 更新数据的时候会触发重渲染，重渲染会经历虚拟 DOM 的比对，可能会引起布局的重新计算，所以，在 React 中打字机效果更新状态时，换成用 ref 直接操作 DOM 去更新文本内容。

解决方案就是：固定对话区域高度，固定尺寸，用 overflow 控制滚动，而不是让容器高度随内容增长。
