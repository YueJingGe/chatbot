## Major（5 条）

### 1. git-branch/SKILL.md：支持已有 release 分支并存时创建新版本

**问题**：当远端存在任意 release/* 分支时，当前流程只要求 checkout 已有分支，没有从最新 main 创建新目标版本的路径。存在 release/v1.1.0 时，无法按 git-workflow.md 新建 release/v1.2.0。

**建议**：同时提供"复用已有分支"和"从 main 创建目标分支"两条路径。

---

### 2. pre-push：远端查询失败时阻止 push

**问题**：ls-remote 查询失败时只输出警告，没有 exit 1。当 origin/main 已经是 HEAD 的祖先时，代码会跳过二次查询，允许远端分支状态未知的 push。

**建议**：在失败分支中执行 exit 1。

---

### 3. ConversationSidebar.tsx：会话选择支持键盘操作

**问题**：第 48 行仅绑定 onClick。键盘用户无法聚焦并选择历史会话。

**建议**：使用原生 button，或补充焦点、角色和 Enter/Space 键盘处理。

---

### 4. QuestionHistoryPanel.tsx：键盘操作

**问题**：面板只在鼠标悬停时展开。键盘用户无法打开面板。问题项也是不可聚焦的 div。

**建议**：使用语义化 button 作为触发器和问题项。为触发器添加焦点展开行为。

---

### 5. useConversation.ts：pagehide 同步保存

**问题**：浏览器刷新或关闭页面不会触发 React 组件卸载清理。用户在 300ms 防抖窗口内刷新页面时，最新消息会丢失。

**建议**：在 pagehide 时清除定时器并写入 pendingSaveRef.current。

```typescript
useEffect(() => {
  const flushPendingSave = () => {
    if (saveTimerRef.current) {
      clearTimeout(saveTimerRef.current);
      saveTimerRef.current = null;
    }
    if (pendingSaveRef.current) {
      saveConversations(pendingSaveRef.current);
      pendingSaveRef.current = null;
    }
  };

  window.addEventListener("pagehide", flushPendingSave);

  return () => {
    window.removeEventListener("pagehide", flushPendingSave);
    flushPendingSave();
  };
}, []);
```
