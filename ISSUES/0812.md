# 新增 skill

```
create-agent-first-docs/             ← Skill 1：初始化项目文档结构（一次性执行）
├── SKILL.md                         ← AI 读取的指令
└── scan.js                          ← 扫描项目结构

agent-first-docs-docs-guard/         ← Skill 2：守卫（初始化之后执行），验证文档结构
├── SKILL.md                         ← AI 读取的指令
└── scripts/
    ├── pre-commit-docs-check.sh     ← 产出物，放入项目的 scripts/ 每次 `git commit` 时候触发
    └── docs-health-check.mjs        ← 产出物，放入项目的 scripts/ 每次 PR / Push 时候触发
```

```
生成 agent-first 文档结构
```

# 执行 agent-first-docs-docs-guard Skill

```
请按照 agent-first-docs-docs-guard/SKILL.md 中的流程，为当前项目配置文档守卫机制

```

## 做接入

```
# 如果用了 husky
npx husky add .husky/pre-commit "bash scripts/pre-commit-docs-check.sh"

# 如果没用 husky
cp scripts/pre-commit-docs-check.sh .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit

```
