## 解决 npx 不在 agent 的 shell PATH 中。

这是系统 PATH 配置问题，不是 skill 的问题。需要你在本机终端执行一次：

```bash
echo 'export PATH="/usr/local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```

执行完后重启 IDE，这样 agent 的 shell 环境就能继承到新的 PATH 了。

skill 本身没有问题，流程完全适用于你的项目。唯一障碍就是 /usr/local/bin 不在 PATH 里。
