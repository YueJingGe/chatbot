# New-equirement-Init 新需求初始化

## 触发条件
当用户提出新的功能需求、修改需求或系统重构任务时，必须自动触发此 Skill。

## 执行步骤
1. **强制读取全局规范**：在回答用户的任何需求或编写任何代码之前，必须首先使用工具读取项目根目录下的 `AGENTS.md` 文件。
2. **读取约束红线**：根据 `AGENTS.md` 中的文档导航，读取 `docs/harness/` 目录下对应的约束文件（如 `code-style.md`, `security.md` 等）。
3. **确认规范加载**：在回复用户时，简要说明已加载项目规范，并确认当前任务是否涉及 iron（铁律）级别的约束。
4. **进入标准工作流**：规范加载完成后，严格按照 `AGENTS.md` 中的“Agent 工作规则”执行，即在 `docs/specs/active/` 下创建 spec 文档对齐验收标准，等待用户确认后再继续。

## 注意事项
- 如果读取 `AGENTS.md` 失败，必须立即停止后续操作并向用户报错。
- 严禁在没有读取规范的情况下直接生成代码或创建文档。
