# 项目 Skill 清单

本项目共注册了 6 个 Skill：

| #   | Skill 名称                    | 说明                                                                 |
| --- | ----------------------------- | -------------------------------------------------------------------- |
| 1   | `karpathy-guidelines`         | AI 编程行为准则，减少过度设计、越界改动，写代码前显式化假设          |
| 2   | `frontend-design`             | 前端视觉设计指导，构建 UI 时做出有区分度的美学选择                   |
| 3   | `harsh-current-branch-review` | 严厉审查当前工作区未提交的代码改动                                   |
| 4   | `eslint-autofix`              | 修改代码后用 ESLint 自动修复格式问题 + 手动修逻辑错误                |
| 5   | `skill-creator`               | 创建新 Skill、修改改进现有 Skill、评估 Skill 效果                    |
| 6   | `dev-agent-skills`            | Claude Code agent skills 和 hooks 插件集合（git 工作流、安全护栏等） |
