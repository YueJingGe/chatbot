# Create Proposal — 需求设计文档生成

## 触发场景

- 用户描述一个新功能或新需求，希望生成结构化的需求文档
- 用户明确要求创建提案、需求分析或设计文档

## 工作流程

### Step 1: 理解需求

从用户输入中提取：

- **核心目标**：这个需求要解决什么问题
- **目标用户**：谁会使用这个功能
- **功能边界**：包含什么、不包含什么

如果信息不足，使用 AskUserQuestion 向用户确认关键细节（最多 3 个问题）。

### Step 2: 分析项目上下文

- 读取项目结构，识别可能涉及的模块和文件
- 检查现有技术方案和架构约束（如 AGENTS.md、docs/harness/）
- 确认是否有数据库层、API 层等相关组件

### Step 3: 生成文档

按以下模板生成 Markdown 文档，所有章节均为必填：

```markdown
# {需求名称} — 需求设计文档

## 一、背景

### 1.1 现状描述
[当前系统/业务现状，为什么需要这个功能]

### 1.2 目标
[期望达成的目标，可量化的优先量化]

### 1.3 适用范围
[功能覆盖的用户/场景范围]

---

## 二、功能清单

| 序号 | 功能点 | 描述 | 优先级 |
|------|--------|------|--------|
| 1    |        |      | P0/P1/P2 |

> 优先级定义：P0 = 必须实现 | P1 = 重要但可延后 | P2 = 锦上添花

---

## 三、涉及模块

| 模块 | 涉及文件/目录 | 变更类型 | 说明 |
|------|--------------|----------|------|
|      |              | 新增/修改 |      |

---

## 四、技术方案

### 4.1 整体思路
[技术实现的整体描述，可附架构图或流程图]

### 4.2 关键实现细节
[核心逻辑、算法、交互流程等]

### 4.3 技术风险
[潜在风险及应对方案]

---

## 五、数据库变更

> 如无数据库变更，注明"本次需求不涉及数据库变更"。

### 5.1 新增表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
|        |      |      |      |

### 5.2 修改表

[ALTER 语句或变更说明]

---

## 六、接口设计

> 如无接口变更，注明"本次需求不涉及接口变更"。

### 6.1 {接口名称}

- **Method**: `GET / POST / PUT / DELETE`
- **Path**: `/api/xxx`
- **描述**: [接口用途]

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
|        |      |      |      |

**响应示例：**

```json
{
  "code": 200,
  "data": {}
}
```

---

## 七、验收标准

- [ ] 功能点 1 验收通过
- [ ] 功能点 2 验收通过

---

## 八、排期建议

| 阶段 | 预估工时 | 说明 |
|------|----------|------|
| 开发 |          |      |
| 测试 |          |      |
| 联调 |          |      |
```

### Step 4: 保存文件

**文件命名规则**：`YYYY-MM-DD-HH-mm-需求名.md`

- 日期时间取当前系统时间
- 需求名使用简短中文或英文，与文件名中的连字符直接连接
- 示例：`2026-08-17-14-30-用户登录.md`、`2026-08-17-09-00-dark-mode.md`

**存储路径**：`{workspace}/Documents/需求分析/需求/`

- 路径相对于工作区根目录
- 若目录不存在，先创建再写入

### Step 5: 确认与反馈

- 告知用户文档已生成的路径
- 询问是否需要调整或补充内容

## 注意事项

- 所有章节不可省略，无相关内容时注明"本次需求不涉及"
- 功能清单必须标注优先级（P0/P1/P2）
- 数据库变更需给出完整的字段定义或 ALTER 语句
- 接口设计需包含请求参数和响应示例
- 涉及模块需基于实际项目结构分析，不可凭空编造
- 技术方案应考虑项目现有架构约束（先读 AGENTS.md 或相关文档）
