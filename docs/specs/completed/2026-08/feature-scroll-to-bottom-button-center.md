# Spec：聊天区域"回到底部"悬浮按钮居中

## 背景

当前"回到底部"悬浮按钮定位在聊天区域右下角。为提升视觉平衡性并减少对用户消息内容的遮挡，需将其水平居中显示在聊天区域底部中央。

## 目标

将悬浮按钮从右下角移动到聊天区域底部中央，保持所有现有功能与交互不变，并确保不遮挡聊天消息内容。

## 验收标准

### 1. 位置与布局

- [x] 按钮水平居中显示在 `.chat-history` 底部。
- [x] 按钮在桌面端与移动端均保持水平居中。
- [x] 按钮保持悬浮在消息上方，不随聊天记录滚动。

### 2. 功能与交互

- [x] 按钮的显示/隐藏逻辑保持不变（未滚动到底部时显示，到底部时隐藏）。
- [x] 点击按钮后聊天区域平滑滚动到最新消息位置。
- [x] 悬停、点击、显示/隐藏动画效果保持不变。
- [x] `prefers-reduced-motion` 媒体查询中的动效减弱逻辑保持不变。

### 3. 无障碍

- [x] `aria-label`、`aria-hidden` 等无障碍属性保持不变。

### 4. 技术实现

- [x] 通过 `App.tsx` 中的 `.chat-history-wrapper` 将按钮移出可滚动区域，避免按钮随消息滚动。
- [x] 通过 `App.css` 实现按钮在聊天区域底部水平居中。
- [x] 修改涉及的样式兼容桌面端与移动端。
- [x] 执行 `npm run build` 通过，无 TypeScript/ESLint 错误。

## 涉及文件

- `web/src/App.tsx`：用 `.chat-history-wrapper` 包裹 `.chat-history` 与 `ScrollToBottomButton`，将按钮移出可滚动区域。
- `web/src/App.css`：新增 `.chat-history-wrapper` 定位上下文，调整按钮居中 transform 与响应式样式。

## 非目标

- 不修改按钮的视觉样式（颜色、阴影、圆角、尺寸除外移动端已有调整）。
- 不修改消息气泡、输入框、头部、页脚样式。
- 不修改 SSE 数据流与消息状态管理逻辑。

## 验证方式

1. 执行 `npm run build`，确认构建通过。
2. 启动项目 `npm run dev`，发送多条消息使聊天区域出现滚动条。
3. 向上滑动查看历史消息，确认按钮在聊天区域底部中央显示。
4. 点击按钮，确认平滑滚动到底部且按钮自动隐藏。
5. 在桌面端确认最后一条消息不被按钮遮挡。
6. 在移动端视口（<=480px）下重复步骤 2-5，确认按钮仍居中且尺寸适配。
