# Spec: 对话功能增加实时日期时间能力

## 背景

当前 AI 对话中，当用户询问日期/时间相关问题时，LLM 无法获取实时信息，会基于训练数据给出过时的回答（如截图所示，回答"2023年10月5日"）。需要在每次对话请求时，将服务器端实时日期时间注入 system prompt，使 LLM 能够基于真实时间回答。

## 方案

在后端 `server.js` 的 `/api/chat` 接口中，构建 system prompt 时动态拼接当前服务器日期时间（格式：`YYYY-MM-DD HH:mm:ss`，包含星期几），作为 system prompt 的一部分发送给 LLM。

**不改动的部分：**

- 前端代码（`App.tsx`、`MessageList.tsx`、`InputArea.tsx`）无需修改
- 数据流链路不变（仍是 SSE 流式传输）
- 不引入新依赖

**改动的部分：**

- `server/server.js`：在 system prompt 中追加实时日期时间信息

## 验收标准

- [x] 用户询问"今天几号"、"现在几点"、"今天星期几"等问题时，AI 能正确回答当前日期和时间
- [x] 日期时间格式对人类可读友好（如"2026年8月14日 星期五 15:30:00"）
- [x] 不影响现有对话功能的正常使用
- [x] `npm run build` 构建通过
