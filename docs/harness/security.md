# 安全规则

> 修改鉴权逻辑、数据处理或涉及用户输入时必读。

## 密钥管理红线

| 红线                     | 说明                                              |
| ------------------------ | ------------------------------------------------- |
| **禁止硬编码密钥/Token** | 所有 API Key 必须通过 `.env` + `process.env` 读取 |
| **禁止提交 `.env` 文件** | `.env` 包含敏感凭证，`.gitignore` 已排除          |
| **环境变量启动校验**     | 启动时校验必需的环境变量是否存在，缺失则退出      |

**必需的环境变量**：

- `DASHSCOPE_API_KEY` — 阿里云百炼 API 密钥
- `DASHSCOPE_BASE_URL` — 阿里云百炼 API 地址
- `MODEL_NAME` — 模型名称（qwen-max）

## XSS 防护

| 规则                               | 说明                         |
| ---------------------------------- | ---------------------------- |
| **禁止 `dangerouslySetInnerHTML`** | 除非配合 `DOMPurify` 消毒    |
| **用户输入自动转义**               | React 默认转义，无需额外处理 |

## 注入防护

| 规则                      | 说明             |
| ------------------------- | ---------------- |
| **禁止 `eval()`**         | 禁止动态执行代码 |
| **禁止 `new Function()`** | 禁止动态生成函数 |

## SSE 安全

| 规则                 | 说明                                          |
| -------------------- | --------------------------------------------- |
| **超时控制**         | SSE 流式请求必须设置超时（`AbortController`） |
| **headersSent 检查** | 错误处理时必须检查 `res.headersSent`          |
| **流结束标志**       | 流结束发送 `[DONE]` 标志                      |

## Git 安全

| 规则                        | 说明                              |
| --------------------------- | --------------------------------- |
| **禁止 `git push --force`** | 禁止强制推送                      |
| **禁止 `--no-verify`**      | 禁止跳过 hooks                    |
| **禁止破坏性 git 命令**     | 如 `hard reset`，除非用户明确要求 |

## 依赖安全

- 新增依赖前评估包体积与维护状态
- 在 `AGENTS.md` 中记录新增依赖及用途
