# 约束导航页

> 本目录包含项目的核心约束文件，Agent 在对应场景下必须读取对应约束。

## 约束文件索引

| 文件            | 级别   | 加载时机                         | 核心内容                           |
| --------------- | ------ | -------------------------------- | ---------------------------------- |
| architecture.md | iron   | 改构建/路由/状态管理/Monorepo 时 | workspace 边界、构建约束、通信协议 |
| code-style.md   | living | 写新代码时                       | 命名/格式/导出/类型红线            |
| security.md     | iron   | 改鉴权/数据处理时                | 密钥管理、XSS 防护、注入防护       |

## 约束级别说明

| 级别        | AI 权限     | 说明                                       |
| ----------- | ----------- | ------------------------------------------ |
| `iron`      | 只读，不可改 | 铁律，违反即故障，仅人工可修改             |
| `living`    | 可提议      | 活约束，AI 可标注 `[PROPOSED]` 提议新增条目 |
| `guideline` | 可自由更新  | 参考指南，修改代码后应主动同步更新         |

## 已有文档说明

项目已有 `docs/reference/` 目录，包含团队自定义的编码和命名规范文档：

- `docs/reference/coding.md` — 详细编码规范（React 组件、CSS、后端 SSE、TypeScript 等）
- `docs/reference/naming.md` — 命名规范（变量、函数、组件、文件、CSS 类、Git 提交）

**优先级**：`docs/reference/` 下的文档为团队自定义资源，优先级高于本体系生成的文档。
