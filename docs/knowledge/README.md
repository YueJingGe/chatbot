# 项目知识库

这是 AI agent 最缺的东西——它不了解你的项目现状。你需要把以下信息写进去：

| 文件 | 写什么 | 为什么重要 |
|------|--------|-----------|
| `project-overview.md` | 项目是做什么的、核心业务流程 | AI 才能写出符合业务逻辑的代码 |
| `architecture.md` | 项目目录结构、模块划分、数据流向 | AI 才知道代码该往哪放 |
| `api-conventions.md` | 接口命名规范、响应格式、错误码约定 | AI 生成的接口风格才统一 |
| `database-schema.md` | 当前表结构、字段说明 | AI 写迁移脚本时不会搞错字段 |
